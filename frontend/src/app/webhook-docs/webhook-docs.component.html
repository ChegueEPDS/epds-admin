EPDS LICENSE INTEGRATION API V1

Developer integration guide

Everything needed to receive ordered license events, verify webhook signatures and upload generated license or mobile app files.

webhook Open tester
01

Create API credentials

SuperAdmin creates an integration in Settings > License integrations. API keys and webhook secrets are shown once.

02

Receive ordered event

Webhook or polling returns a license.ordered event containing the license ID and customer license details.

03

Upload file

Use the license ID with the matching upload endpoint. License files move ordered licenses to pending; APK uploads replace the current mobile app file.

Webhook headers

X-EPDS-Event-Id
Globally unique event ID.
X-EPDS-Timestamp
Unix timestamp in seconds.
X-EPDS-Signature
v1=<hex HMAC-SHA256>

Signature verification

{{ signatureBase }}

Reject timestamps older than five minutes and compare signatures using a constant-time function.

Operational responses

400 Invalid input or idempotency key 401 Missing or invalid API key 403 Missing API scope 404 License not found 409 Idempotency conflict 413 File too large 415 Unsupported file content 429 Rate limit exceeded
